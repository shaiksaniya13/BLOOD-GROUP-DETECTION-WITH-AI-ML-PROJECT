# Blood Group Detection using AI & Machine Learning

# Project Overview
This project focuses on detecting a person’s **blood group automatically using AI and Machine Learning techniques**.  
The system analyzes biological data (such as blood cell images or extracted features) and predicts the blood group accurately.

The aim is to **reduce manual testing time**, minimize human error, and support healthcare systems with faster blood group identification.

---

# Problem Statement
Traditional blood group detection methods are:
- Time-consuming
- Manual
- Prone to human error

There is a need for an **automated, fast, and accurate system** to detect blood groups using machine learning.

---

# Proposed Solution
- Use machine learning algorithms to classify blood groups
- Train the model on labeled blood sample data
- Predict blood group based on learned patterns
- Provide quick and reliable results

# Dataset Description
The dataset contains:
- Blood sample images
- Corresponding blood group labels (A, B, AB, O with +/−)

Data preprocessing includes:
- Image resizing
- Noise removal
- Normalization

---

#How the System Works
1. User uploads a blood sample image
2. Image is preprocessed
3. Features are extracted
4. ML model predicts the blood group
5. Result is displayed to the user
